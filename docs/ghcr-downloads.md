# GHCR download statistics

![GHCR downloads over the last 90 days](ghcr-downloads.svg)

This chart tracks the cumulative download count for `ghcr.io/gordonbeeming/copilot_here`.

The [raw history](ghcr-downloads.csv) is updated daily by the [Track GHCR downloads workflow](../.github/workflows/track-ghcr-downloads.yml). The repository keeps a rolling 90-day history, so daily changes can also be derived from consecutive rows.

> The history starts when the tracker first runs; GitHub does not provide historical daily pull data retroactively.
